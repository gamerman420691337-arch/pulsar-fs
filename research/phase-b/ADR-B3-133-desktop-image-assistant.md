# ADR B3-133: Desktop image assistant preparation

Status: implementation tested; roadmap PARTIAL; unqualified.

Expose registered vision capability in the desktop assistant through the shared client authority interface. Select an imported source rather than a host path. Require exclusive synthetic scope; supervised normalization must issue the image context. Share draft/context validation with the CLI, checking source and namespace before any private intent publication. Preserve separate inference and generation approvals and exact immutable saved-request retry behavior.

Clear project-scoped choices on binding changes and retain the existing stale-reply refusal. Present source and normalized identity in saved request review. Label still images as themes without observed temporal motion. Do not infer frame support from the generic source catalog; decoding is authoritative.

Controller and headless-rendering tests are software evidence. Native socket/desktop observation and useful model quality remain distinct gates. Preserve prior quality failures and the absent annotation decision.

Scope and evidence: [desktop implementation](../../docs/PULSAR_DESKTOP_IMAGE_ASSISTANT.md).
