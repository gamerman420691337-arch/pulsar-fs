# ADR B3-054: Measured live CUDA admission and sealed observer loader

Status: Implemented and verified for live memory observation/admission. Persistent GPU live inference remains disabled.

Use the live manifest and its inherited absolute monotonic deadline to observe native GPU memory without manufacturing an offline request. A separate sealed live relay declares only the memory-observation role. Its initial child verifies the actual mounted bytes before selecting the captured loader; the loader process reads the fully sealed descriptor, checks the exact role/manifest/deadline and independently verifies mounted bytes again. The deadline is never renewed by either stage.

Share the sealed descriptor transport, bounded parent pipe supervision, CUDA/NVML query and conservative capacity/freshness checks with the existing offline observer. Keep the original offline relay and flat memory-reply wire fields unchanged. Live replies have a distinct manifest binding and sample envelope and cannot be read as offline replies. Supplier native code runs only in the confined observer.

Complete native initialization and integrity checks before taking the actual admission sample. Re-query NVML rather than renewing an earlier timestamp; preserve the same-host sample time through parent validation, exact process retirement and aggregate admission. Reject future or older-than-one-second samples, inconsistent capacities, wrong device coordinates, altered manifests and owner/capture mismatches. Total and available memory use conservative minima across the CUDA SDK and NVML.

Only a successful supervised observer can construct the process-local observed capability. Its interactive admission rechecks the loaded owner policy and exact supervised capture, then enters shared aggregate CPU/GPU accounting. The admitted capability retains the image, pinned device, reservation, manifest hash and original deadline for the future stream launcher. A changed manifest or expired lease cannot take those launch parts. No declaration, reply or serialized restart record reconstructs admission.

The actual native fixture uses the captured 75-library image and pinned NVIDIA nodes/modules. It measures real CUDA/NVML identity and capacities, admits a 96 MiB interactive claim above the owner's 64 MiB offline allowance, refuses another claim, preserves image ownership across probe retirement, preserves the original lease, and confirms cancellation releases the complete group/image/resource ownership. It loads no model and executes no persistent inference. Existing offline observation and both live/offline mount-custody cases are rerun after the shared refactor. Direct initial/exec role, missing relay, unsealed relay and sealed malformed relay cases must refuse before native loading.

An initial compile failure was limited to missing mutable bindings in the new test helper. The first native fixture run refused the helper's temporary directory permissions before constructing the live observer; its exact source/archive subject and raw log are retained. The corrected fixture sets mode 0700. Neither correction changes production behavior.

The [evidence packet](../../docs/evidence/roadmap-2026-10-07/live-cuda-memory/) records source archives, raw gates, measured readback and terminal identities. Activation still requires the persistent inference role, model snapshot binding, parent/worker transcript correspondence, original final CUDA receipt/trace verification and custody through exact retirement. Fastest-preset live six-axis generation, independent latency/quality, recovery/IO, physical Handy, platform and human/release gates remain open.

The [terminal checkpoint](../../docs/evidence/roadmap-2026-10-07/live-cuda-memory/checkpoint.json) records 986 workspace passes (53 ignored), 518 CUDA-feature passes (50 ignored), both explicit native observers, seven live and five offline mount-custody cases, five shipped CPU application cases without skips, four direct/relay refusals and 255 structural checks. All 342 live/archive source records, 65 executable identities and 78 terminal input identities match. The saved manifest independently matches the measured reply and exact current worker. No model or persistent inference was executed.
