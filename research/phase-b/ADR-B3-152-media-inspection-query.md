# ADR B3-152: inspect captured media through a scoped worker query

Status: implemented software slice, qualification open. Date: 2026-10-12.

The advertised standalone info command previously refused. Container declarations belong to a bounded read query, rather than generation or client-side path authority. Capture through the existing project import, authorize an exact revision, and run ffprobe over the immutable source inside the existing CPU worker boundary. Return a typed, strictly scoped metadata report with mandatory false decoding/qualification flags and no generated artifact references.

Recheck authority/revision around admission and after joined execution. Use unique attempt identities for leases; include probe leases in source eviction protection and post-commit scoped revocation. Persist the inspection project/source for review and expose that behavior. Remove only the successful empty owned attempt directory; preserve failure custody rather than recursively deleting unknown egress.

Verification and limitations: [media inspection](../../docs/PULSAR_MEDIA_INSPECTION.md). Synthetic fixtures and compilation establish software behavior only; the full roadmap remains PARTIAL.
