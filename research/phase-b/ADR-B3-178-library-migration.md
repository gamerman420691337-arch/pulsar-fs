# ADR B3-178 — explicit linked continuation of stopped local batches

Status: implemented software checkpoint; qualification remains open.

Explicit local-library migration now creates a linked successor for unfinished entries under a checked replacement recipe, reusing captured sources and imported projects. The original batch is fenced from new generation and retains accepted jobs, completed entries and outputs. Positively acknowledged failed/cancelled jobs can obtain a fresh successor generation intent only after current terminal state and absent Worker ownership are checked; their original receipts remain unchanged. Unknown pending effects, missing positive receipts, active/interrupted work, uncommitted candidates and cancelled batches refuse. Exact report observation, current grants/revisions, fresh pack admission, immutable retry content, bounded lineage and successor-first metadata release are enforced. Reader floor is 32. Engine tests pass 888 with 70 ignored; unchanged Client/Protocol subjects retain passing 394/286 suites with ten/zero ignored. Both strict lint configurations, Windows source check (with existing warnings), native/helper builds, formatting, architecture and 36 guards pass. Native CLI/desktop migration, restart/retry, wrong/stale intent refusal, source/project reuse, predecessor refusal without database mutation, completed-prefix preservation and actual failed-Worker recovery pass. Nine published scripts match the authored detector oracle. Full roadmap PARTIAL; rendered GUI, broader faults/views/watching, unknown-effect disposition and useful model/media/platform/Handy/human/release qualification remain open.

Keep accepted history on an immutable original and create a separate explicitly scheduled successor. Positive receipt and terminal Worker-state checks authorize replacement of a failed job; absence of an acknowledgement does not. Shared captured-source membership and a parent report digest retain custody without source rediscovery. Transactional lineage and a new reader barrier prevent an older Engine from interpreting the stop as resumable work.
