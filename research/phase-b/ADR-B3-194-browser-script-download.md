# ADR B3-194: Export an inspected master through a retained original intent

Bind browser script download to a separately inspected committed revision and
program digest. Prepare and sync an immutable original request and private pinned
output directory before the Engine export; retries retain the same identity.
Read and compare the actual Engine-produced bytes before browser delivery.
Unavailable gaps and millisecond collisions refuse rather than fabricating motion.

Retain journals/directories through unknown outcomes. Managed release and recovery
remain explicit follow-up work; no journal becomes independent execution authority.

See [contract and evidence](../../docs/PULSAR_BROWSER_SCRIPT_DOWNLOAD.md).
