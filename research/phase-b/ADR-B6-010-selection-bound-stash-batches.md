# ADR B6-010: Stash batch pack intent remains revision-bound

Status: implemented; local evidence retained separately.

Record an optional exact pack choice and its admitted typed profile in Stash batch intent. Refuse simultaneous file-model intent. Prepare selected pack admission before remote discovery and recheck choice when publishing the ledger. Each scene uses the dedicated pack-generation command, current project grants, fresh pack integrity/admission and existing captured dependency publication. Extend the internal exact-request permit to the profile's expected model digest; do not transform pack intent into a file-model command.

Deactivation prevents future admissions; accepted jobs and historical receipts retain their captured inputs. Resume reuses the old phase/choice and cannot infer approval from a new selection of the same manifest. Explicit migration under the observed stopped-ledger digest may choose a new pack, file model or no custom model. Reconcile accepted generation before superseding unaccepted intent, preserve previous choices/options/model digests and later effects, and remain paused until resume.

Use report schema 4 and a conditional schema-13 database barrier for durable pack batch/migration authority. Validate stored pack choice/profile correspondence during the read-only startup probe, with the 16 MiB record limit applied in SQL before Rust string allocation. Preserve that barrier through selection, placement and imported interval recovery. Keep non-pack schema-2/3 report encoding and request fingerprints unchanged by omitting absent optional fields. Portable format 9 and finite worker contract are unchanged.

The native authored fixture proves local CPU generation and loopback/no-clobber publication, deactivation refusal, stale resume, explicit replayable migration, restart and exact preceding-reader refusal. Synthetic receipt tests cover accepted pack acknowledgement reconciliation. None of these closes installed Stash, learned-model quality, native GUI, Handy, platform, rights or release qualification.
