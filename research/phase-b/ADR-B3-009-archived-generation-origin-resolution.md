# ADR B3-009: Resolve historical generation facts through retained namespaces

Decision: share the existing verified archive namespace loader between retiming inspection and generation origin inspection. Factor originating clock verification into a reader-based core, retaining the native path wrapper and its validation ordering.

Imported generation records are historical evidence, not local jobs. Inspection checks the current imported anchor against its immutable projection, follows exact candidate namespace maps and validates original typed worker evidence. Canonical motion, worker manifests/receipts and raw output are selected from the declared object closure and read through anchored engine-owned storage. Original request paths are never resolved or executed.

The public report carries bounded original identities, source/configuration and optional checked clock summaries, with explicit archival/no-active-job/no-publication-authority/no-qualification flags. Unplaced origins cannot assert sampled clocks. Current rebased aliases, edited descendants and master-motion source purity require separate ancestry work before publication.

No database or portable-format version changes are needed for this read-only command. Existing schema 9 and portable format 8 stay in force. Earlier readers do not gain the new command or any additional publication authority.

Validation: see [retained origin inspection](../../docs/PULSAR_ARCHIVED_GENERATION_ORIGINS.md) and its source-bound local receipt. Synthetic checks do not close media, device, platform, model or human acceptance gates.
