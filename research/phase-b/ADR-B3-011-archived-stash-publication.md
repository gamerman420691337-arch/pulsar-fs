# ADR B3-011: explicit retained-origin Stash publication

Status: implemented locally; unqualified for release.

Imported jobs and source associations cannot become local execution authority. Publication of an edited imported master nevertheless needs its original source clocks and verified current ancestry.

Choose an explicit retained manifest reference alongside the original imported anchor and historical job. Reconstruct placed clocks only from checked retained objects, compose verified ordered native/archival retiming, and recheck the committed master under current authorization. Require fresh source/scene/file binding and retain existing no-clobber dispatch. Unplaced origins use the original elapsed convention and explicitly lack sampled-clock evidence.

Retain proof schema 3 with explicit origin/master context and no active job or release qualification. Advance the database to schema 10 atomically with the first archival outbox, so preceding readers cannot consume new historical receipt semantics. Preserve native proof schemas 1/2 and fresh/native-only schema 9. Portable format remains 8.

Exact replay and query-only observation retain uncertain dispatch without resending. Missing provenance or mixed clocks refuse. See [implementation and limits](../../docs/PULSAR_ARCHIVED_STASH_PUBLICATION.md) and its source-bound local receipt. Broader correspondence, actual Stash, model/media, GUI, Handy and release gates remain open.
