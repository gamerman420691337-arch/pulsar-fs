# ADR B3-153: shared visual tier admission and bounded background recovery

Date: 2026-10-12. Status: implemented software slice, qualification open.

Expose already admitted Maximum/quality visual recipes and source-frame stride through the public generate command. Validate the shared execution contract before project/source creation. Preserve source timestamps rather than translating a legacy FPS switch into guessed frame sampling.

The actual consumer campaign demonstrates a geometry defect in Maximum background sampling on small supported views. Preserve original points and strict Core checks; add distinct source-pixel background points inside the exact search margin only when existing support is insufficient, outside both target exclusions and within the unchanged 64-point budget. Version the Maximum plan and disclose actual recovery sampling. Default/Fast recipes are unchanged.
