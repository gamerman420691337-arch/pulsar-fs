# ADR B3-093: apply retained observed target proposals through normal generation

Decision: add explicit target focus to assistant Start and resolve it only in the current checked Engine catalogue. Hash the exact captured facts with the assistant context. Apply a separately approved completed target proposal by deriving an unclassified seed and captured video view, preserving normal generation admission and original receipt identity. Recheck during publication. Refuse stale references, source/view conflicts and competing declarations.

Keep legacy empty focus context/wire bytes and saved stride JSON stable. Saved target requests bind the displayed ID to the approval digest and use the existing private store, pinned desktop file review and exact dispatch. Original accepted receipt replay remains historical; fresh execution requires retained facts and current authority.

Consequences: ephemeral references intentionally do not survive preview replacement or Engine restart. Inference/target proposals do not authorize motion commit or playback. Detector contracts, sampled lattice, model capture and protected commits remain independent checks. Qualification requires native learned execution and actual media/hardware/human evidence; fixture success is insufficient.
