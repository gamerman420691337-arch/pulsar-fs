# ADR B3-092: capture checked preview target references

Decision: keep selectable detector geometry in a bounded ephemeral Engine registry, scoped to authenticated project/session and revision. Capture only after existing worker/frame custody validation. Bind IDs to complete displayed-frame, detector and view facts. Offer only unambiguous observed box centres and infer no class or anatomical identity.

A read-only command returns current references. Restart, revision mismatch, owner mismatch and ineligible replacement hide or clear them. Bound retained slots and aggregate memory explicitly. Preserve existing proposal approval behavior: this prerequisite does not yet authorize target application or offer target IDs to assistant inference.

Consequences: later Start context and approved generation must resolve these retained IDs under current ownership/revision and original proposal/context fingerprints. They must reject changed previews, view conflicts and mismatched sources. Saved client intent and desktop controls need separate target-aware implementation and tests. Catalogue fixture passes cannot close learned-media, hardware or human gates.
