# Saved assistant edit recovery

Status: PARTIAL full roadmap progress; qualification INCOMPLETE.

Use `pulsar assistant prepare-edit PROJECT ATTEMPT --revision REV --request-id ID --output /absolute/private/edit.json` to capture a completed edit proposal and its current checked recipe without applying it. Apply or retry with `pulsar assistant apply-saved-edit --intent /absolute/private/edit.json --approve-edit`. Existing immediate `apply-edit` remains available. The private file records the original request, revision, approved context/proposal digests and full recipe operation/axis/program identity. It contains a credential namespace hash, never the session token.

Files use the existing bounded (32768-byte), owned, no-follow, single-link private store. Publication refuses overwrite. Reading rejects public permissions, links, excessive bytes, unknown fields and inconsistent metadata. Recipe identity binds its operation, axis, program, project and revision; the approved proposal digest must match the displayed recipe ID. Edits and generation have separate saved schemas and approval controls.

The desktop can save a current proposal, restore a saved path, review the captured operation and source program, then explicitly approve the saved edit. Restore resets that approval and does not dispatch any mutation. Applying reloads and checks the same reviewed semantic digest and current credential namespace. Lost acknowledgements preserve the original pending request. Read-only refreshes cannot replace it; another request, changed file or replacement restore cannot displace it. A successful reply yields one candidate handoff and displays the accepted candidate ID/base revision.

Restoring historical revision declarations is allowed for exact receipt recovery. The existing Engine authorizes Read/Edit before replay and can return an accepted candidate even after revision changes or reopen. A fresh request still needs the original current revision, retained completed proposal and original Engine lifetime; a saved file cannot recreate expired authority. A recovered old candidate remains stale for commit and requires ordinary rebase/review. Manual restore does not claim automatic startup discovery, withdrawal/resolution of never-accepted requests, or rendered crash recovery qualification.
