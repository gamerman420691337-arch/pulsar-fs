# Single-file offline runtime candidate

Pulsar provides runtime-pack SOURCE_DIRECTORY NEW_ARCHIVE on Linux x86-64. Both paths must be absolute and avoid symlinked components; the existing destination parent must be owned by the current user and not writable by other users. The destination must be new. runtime-install now accepts either the existing directory format or this single archive and publishes only into a new directory.

Both commands run before Engine configuration. They need no HOME, state directory, inference service, network or credentials. Packing/extraction never activates a model or creates an assistant approval policy.

Version 1 is uncompressed: PULSARRT0001, a four-byte little-endian original-manifest length, that original JSON, then payload bytes in declared record order. The original manifest is bounded at 64 KiB. Its existing finite schema/file admission and qualified:false remain mandatory. Streaming uses 64 KiB buffers, exact lengths/SHA-256 and stable file metadata. Header/manifest/truncation/trailing-byte or payload-integrity failures refuse publication. No general-purpose extractor or archive-supplied link records are used.

Packing creates a private0600 temporary file, synchronizes it and publishes with atomic no-overwrite rename. Extraction retains [private staging and publication](PULSAR_OFFLINE_RUNTIME_INSTALLATION.md) and [recognized-stage recovery](PULSAR_RUNTIME_STAGE_RECOVERY.md). Existing archives and installed destinations remain untouched. Parent-sync failure explicitly reports publication with uncertain durability. New packers retain recognized locked construction stages with [explicit inspection/discard](PULSAR_RUNTIME_ARCHIVE_STAGE_RECOVERY.md). Legacy opaque temporary archives remain outside that workflow. Automatic scavenging and exhaustive filesystem/power-loss behavior remain open.

The [checkpoint](evidence/roadmap-2026-10-11/runtime-archive/checkpoint.json) records exact source/build/native results and retained artifact identities. Unit fixtures cover malformed/truncated/trailing/late-corrupt input and source corruption. The native test uses the actual fifteen-payload supplier, hostile umask0777, no HOME/state and disabled network; it verifies every extracted hash, original manifest/receipt, existing destination preservation and late corruption refusal. These tests establish candidate transport integrity, not useful generation quality or release acceptance.
