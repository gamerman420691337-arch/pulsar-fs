# Explicit six-axis audio synthesis

`audio-synth --bundle --bundle-recipe recipe.json --output new-directory` generates one checked candidate with stroke, surge, sway, roll, pitch and yaw tracks from one captured audio source. Output is a new directory containing `stroke.funscript`, `surge.funscript`, `sway.funscript`, `roll.funscript`, `pitch.funscript` and `yaw.funscript`. This directory format does not settle external companion naming or physical axis calibration.

The recipe contains exactly six distinct `channels`, each with `mapping` (`axis`, `amplitude`, `offset`), `mode` (`envelope`, `beats`, `vibe`) and `analysis` (`band`, `threshold`). Mapping and analysis use the existing checked numeric limits; unknown fields, duplicates, missing axes and invalid values refuse. `band` is full/bass/mid/high and threshold is in [0.05,0.9]. Bundle recipes always explicitly gate the envelope; the legacy single-axis full-band default remains ungated. Single-axis CLI controls must retain defaults when a bundle recipe is supplied. No auto-chosen multiband recipe, device adaptation, suction channel or physical interpretation is implied.

The [authored fixture recipe](evidence/roadmap-2026-10-12/audio-bundle/final/recipe.json) is a test declaration, not a recommended creative or device profile. The [checkpoint](evidence/roadmap-2026-10-12/audio-bundle/checkpoint.json) records verification and limits. The authored native campaign passes all six exports and independent PCM/action oracles, four pre-generation refusals, deliberate partial-publication preservation and exact recovery. Engine/Clients/Protocol suites pass 852/327/157 tests with 70/8/0 ignored. Both strict lint configurations, Windows source check, native build, formatting and architecture/source guards pass. The initial compile check failed on a missing `Context` import; its corrected check and final suite results are retained. These tests are not real-media or physical qualification.

Worker decodes one immutable source into calibrated 16 kHz mono PCM and evaluates each declared mapping through the same single-axis DSP implementation. Tracks keep the admitted source sample clock. Receipts record each axis's algorithm, band/filter/gating details, decoded timeline and unqualified synthesized evidence. Band filter delay remains uncompensated; onset mode means RMS threshold crossings, not musical beats. Vibe uses the existing 8 Hz carrier and silence holds its center.

The command creates a new private generation project, imports the source, generates one candidate, commits it and exports each axis using Engine authority. It prints the retained project identity before generation. Existing output directories refuse before any new project. Existing scripts are never replaced. A publication failure can leave completed exports and a committed project; the error reports project/revision and completed paths for explicit `export-axis` recovery. Individual mode has no automatic retry or aggregate atomic transaction. Optional [atomic publication](PULSAR_NEUTRAL_BUNDLE_PUBLICATION.md) stages all six exports and exposes explicit exact-intent resume. Empty reserved directories can remain after earlier failures. Standard exported scripts contain neutral actions, while source/lineage/review evidence remains in the private project.
