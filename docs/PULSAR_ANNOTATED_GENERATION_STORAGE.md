# Annotated generation storage and reader barrier

Annotated attempts now have a conditional schema-23 reader requirement and immutable membership bound to the exact canonical request digest. The store preserves the existing schema-20, live-evidence schema-21 or capture schema-22 layer. Later CUDA publication retains header 23 instead of erasing the annotated reader requirement. Existing capture originals remain byte-identical in authored coexistence tests. See [ADR B2-007](../research/phase-b/ADR-B2-007-annotated-generation-reader-barrier.md).

Read-only startup validation runs before writable SQLite/WAL, creation custody and recovery. It checks exact layouts, marker singleton, membership completeness, manifest digests, explicit CPU profile and dependency identities, source identity, project revision, job/attempt correspondence and retry history. Historical request paths are never opened. Retention uses the existing job transaction plus a savepoint; failure restores the preceding header and tables. Public generation remains guarded, so this retention hook is staged infrastructure rather than an enabled annotated workflow.

Bounds are 4,096 annotated attempts, 1 MiB per manifest and 64 MiB aggregate member manifests. Serialization refuses before growing beyond the per-manifest bound, and validation reserves memory before loading payloads. SQL checks bound scalar metadata before Rust allocation. These explicit limits currently refuse excess history; a retention/disposal policy remains required.

The current Engine reopens a valid authored annotated store. Corrupt manifests, missing membership and a downgraded header refuse before recovery while database, WAL and custody-file hashes remain unchanged. A separately retained preceding application also refuses an isolated schema-23 header fixture without changing the observed database/WAL bytes. That older-reader probe is header-only, not a complete-project migration qualification.

The final serial workspace gate passes 1,079 tests, with zero failures and 60 ignored. The [checkpoint](evidence/roadmap-2026-10-08/annotated-generation-storage/checkpoint.json) records additional gates, exact source/archive identities and retained intermediate logs. No user production database was migrated; only owned authored fixtures exercised publication. No model fitting, live/sterile input access or physical playback occurred.
