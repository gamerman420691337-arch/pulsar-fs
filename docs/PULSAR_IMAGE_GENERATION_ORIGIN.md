# Image-conditioned generation origin

Status: scoped implementation and checks PASS; full roadmap PARTIAL; unqualified.

An approved image-conditioned synthetic proposal now produces a bounded immutable origin record alongside its deterministic pattern input. The record contains the original approval request ID, exact approval and completed report, prepared image context, registered worker/runtime/model/projector identities, and a hash of the exact patterns. It explicitly records no observed temporal motion and no qualification. It contains no authentication token or host asset path.

The normalized RGB is copied into the Engine snapshot store before dispatch. A reserved metadata dependency links the origin and historical image/model identities into the existing worker manifest and receipt. Candidate publication checks the retained record and pixels and refuses a worker that omits declared provenance dependencies. Ordinary direct pattern and text requests retain their current encoding and behavior. Stored origin records are inert evidence and confer no inference, device or commit authority.

Portable capture uses optional typed origin/RGB references and conditional package format 13, includes the origin and normalized pixels as required dependency evidence and checks the image against the same-project source catalog. Inert import validates bytes, patterns, namespace and source correspondence without opening any paths stored in the worker manifest. Missing or changed records/pixels are refused rather than reconstructed from an unrelated current image. Model binaries remain declared identities; this does not create an executable portable model pack.
