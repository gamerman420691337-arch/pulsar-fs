The Engine now derives a clock carrier for each current stroke action through verified generation leaves, unchanged rebase aliases, replayed authored edits, recorded merge masks, replacement commits, undo/redo restoration and verified retiming. Actual CAS motion is checked at every edge. Equal positions never establish origin: a merge's recorded mask selects the input first, and exact action time/value checks then verify that selection. Inserted edit timestamps inherit only an unambiguous common neighboring carrier or a uniform base clock; ambiguous cross-carrier insertions refuse.

The walk limits depth to 128, nodes/carriers to 2048 and effective sample anchors to one million. Cycles, altered restoration motion, invalid/overlapping contribution intervals and unsupported correspondence refuse. The final mapped motion is compared with the selected anchor's existing durable proof; a difference refuses publication until a versioned proof covering all carriers is available. No new protocol or proof format is introduced.
