# Inspect retained neutral bundles before recovery

`export-bundle-inspect ABSOLUTE_STAGING_PATH` authenticates the retained private bundle intent using the current local session, holds the existing exclusive directory lock and reads the exact current master revision. It compares each present neutral script with the master and reports the six captured request identities, per-axis presence/match, destination presence and whether all six local members match. Missing members are observations; corrupt or mismatched present members refuse the command.

The command creates no export reservation, generation job or publication. It does not modify or delete staging or destination files. It refuses active ownership, wrong credentials/schema, changed intent, stale master revision, unrecognized members, unsafe ownership/permissions, links and changed/replaced members. Existing publisher verification additionally checks intent metadata stability. Missing files never satisfy publication verification.

`engine_export_outcomes_verified` is always false. Local content cannot establish the outcome of an Engine export request. Inspection is an observation while the helper owns the lock; it is not permission to retry, a publication receipt or a promise about later filesystem state. Exact-intent `export-bundle-resume` continues to authenticate and reconcile the original identities and refuses unknown Engine outcomes. Inspection currently accepts recognized staging paths, not published destination directories. No new discard, automatic retry or folder scheduler is supplied.
