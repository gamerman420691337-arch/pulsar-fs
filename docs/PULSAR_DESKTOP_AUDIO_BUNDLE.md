# Desktop six-axis audio authoring

Select Audio-derived motion in Generator, then enable Six explicit neutral axes. Expand each axis to choose its own envelope/onset/vibe mode, Full/Bass/Mid/High band, RMS threshold, amplitude and offset. Generate six-axis audio candidate proposes one uncommitted candidate through the shared checked Protocol input. Review and commit separately; use existing selected-axis export to publish neutral scripts.

Single-axis defaults remain Full/envelope/stroke, threshold 0.35, amplitude 0.5 and offset 0.25. Full/default still omits analysis and retains the legacy ungated envelope. Switching between modes preserves independent drafts. Six-axis channel defaults are editable authoring values; they are not approved device or creative profiles. All bundle recipes explicitly gate quiet windows, including Full band. No channel silently inherits a different axis's settings.

Any invalid channel disables generation. Busy state, absent project or absent admitted media source also disable submission. Desktop captures exact source identity and checked settings, then sends through the current project/revision authority. Generation leaves committed motion unchanged until explicit candidate approval. Source clocks, DSP, synthesized evidence and unqualified lineage use the [audio bundle implementation](PULSAR_AUDIO_BUNDLE.md).
