# Independent image-relative motion evidence

The first-party fixture harness now supports an authored rectangular patch `[24, 231, 800, 737]` in the pinned public image. At each two-frame-per-second source interval, it moves the patch by six original pixels upward or downward, then moves the whole image downward by six pixels. Exposed pixels use RGB114. The rectangle is a fixture recipe, not an annotation or segmentation claim. No real-media training labels are created.

The independent checker derives expected target, background and relative image translation from the source recipe and actual decode height. It requires continuous selected identity, three consistent supported points per region, inferred tail evidence, the unchanged half-pixel tolerance and exact independently predicted standard action timestamps and rounded positions. It distinguishes unavailable support/export from incorrect supported motion.

The upward predecessor produced five supported pairs and an unavailable final model-sized pair because unrelated association ambiguity blocked the selected target. The scoped tracker correction retains global ambiguity reviews and blocks only affected selections, including fresh identities from ambiguous detections. Unit coverage distinguishes unrelated ambiguity from actual selected-target ambiguity. Detector generation now records recipe v4; historical v2/v3 remain readable through the checked receipt path.

The final native campaign passes six pairs in each direction at both model-sized and explicit small decode sizes. Downward exports are `[50, 51, 51, 52]`; upward exports are `[50, 49, 49, 48]`, at original times 0, 500, 1000 and 1500 milliseconds. Maximum displacement errors are 0.040300 and 0.015937 analysis pixels respectively. The formerly blocked upward frame retains its class-5 selected identity, six supported target points and the unrelated-ambiguity review. Separate tests still withhold actual selected-target ambiguity. Camera-only 6- and 18-source-pixel campaigns continue to pass; 36 pixels remains PARTIAL with one inconsistent pair and standard export refusal.

Final native results, exact source/binary identities and retained predecessor receipts are recorded in `evidence/roadmap-2026-10-11/relative-motion/checkpoint.json`. This transformed public-image fixture does not qualify target-model accuracy, arbitrary media or camera motion, anatomical stroke, performance, physical Handy behavior, native GUI or release acceptance. All M1-M8 scope remains open until its own evidence exists.
