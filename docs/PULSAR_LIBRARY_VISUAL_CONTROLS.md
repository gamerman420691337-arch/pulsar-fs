# Desktop visual library recipe controls

The Library batches panel can author a visual Stroke recipe directly. Choose Visual stroke recipe, a supported preset and frame sampling stride. Optional file models require an absolute model path and either a declared inference profile or the visible YOLO channel-major RGB/NCHW class count and dimensions. Analysis dimensions and detector threshold have explicit override controls. With no dimension override, the shared folder authoring contract uses profile-derived analysis dimensions, a 640×640 raw detector input, or 320×180 model-free analysis as applicable.

Clicking Capture freezes form values before background work. Profile loading, checked recipe construction and bounded media discovery run outside the graphical frame. Successful intake becomes the exact retained Prepare action; changing the form or profile file afterward cannot replace its retry content. Known local loading or discovery failures leave the form editable and claim no dispatch. Engine capture, generation and selected-axis publication retain their existing authorities and reader floor.

JSON intake remains available for source views and advanced settings. The direct editor does not select or approve model packs, infer tensor layouts, provide source-matched annotations or certify model usefulness. Existing companion outputs and visual bundle destinations remain protected.

See the [checkpoint](evidence/roadmap-2026-10-12/library-visual-controls/checkpoint.json) for actual validation scope. Headless input and native controller evidence do not establish rendered-window usability, model/media accuracy, physical device or human/release acceptance.
