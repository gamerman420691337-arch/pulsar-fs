# Standalone media inspection

2026-10-12. Shared Engine/Worker software increment; full roadmap remains PARTIAL.

`pulsar info /absolute/path/to/media` now captures the source using the existing authorized project import, then requests a bounded metadata query over that immutable snapshot. The preceding CLI dispatch explicitly refused standalone media probing. Successful output is JSON containing source identity, project/revision, format, declared duration and stream codec/dimensions/frame rate or audio sample rate/channels. The command prints the inspection project ID to stderr. It retains a private inspection project and captured source; failed capture can also retain an empty project. Inspection does not create motion, generation jobs or candidates.

The query requires a project, read grant, session and exact current revision. It verifies authority/revision before admission, at the worker fence and again after joined execution. Each concurrent invocation has a unique attempt/lease identity. Active probe leases protect the source from eviction and are cancelled only after a successful scoped revocation commit. The existing isolated native CPU worker executes pinned ffprobe with a 512 MiB memory budget, one CPU thread, at most 30 seconds and 64 KiB output. Metadata reports admit at most 64 streams and reject malformed labels, dimensions, rates, identities and decoding/qualification claims. Probe manifests refuse model-runtime, independent-audio and CUDA attachments; typed replies must match the manifest and contain no generated artifact references.

This is container metadata: both `decoded` and `qualified` must be false. Declared duration or frame rate is not verified frame timing, playback compatibility or generation accuracy. Successful joined queries remove only their empty owned attempt directory; failed worker paths can retain staging under existing retirement/custody rules. A corrupt source remains captured in its inspection project after the query refuses.

The authored offline CLI campaign uses FFV1 video at 64×48 and 8 Hz, PCM audio at 48 kHz/one channel, and combined media, each one second. All three return the exact expected declarations and captured source hash; corrupt and missing files refuse. Original files remain unchanged and the private database has zero jobs/candidates. These fixtures are plumbing controls, not real-media qualification. Authority tests refuse missing/stale revision, ungranted session, unknown source and funscript purpose twice, before worker admission; project bytes, jobs and attempts remain unchanged. Separate controls cover eviction protection, transaction rollback/scoped revocation, native fixture identity and protocol claim/bounds refusals.

The initial implementation reached a worker on stale revision because generic read authorization does not enforce mutation revision checks. That failing regression is retained; explicit query checks correct it. Initial compilation and strict-lint failures are also retained, with final receipts distinguished from them.
