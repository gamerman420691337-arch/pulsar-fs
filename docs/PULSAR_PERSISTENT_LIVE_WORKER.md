# Persistent confined temporal inference

The engine library now has a persistent CPU worker transport for opaque issued RGB pairs. One isolated process loads one pinned temporal model and serves an ordered stream of pairs. An authored native runner has exercised this path. [Authenticated capture leases](PULSAR_AUTHENTICATED_LIVE_INFERENCE.md) now launch and consume it with explicit model/profile admission; physical dispatch remains false.

A strict private manifest binds attempt, capture/source/project/revision identity, the admitted presentation clock, worker/model/runtime byte identities, explicit CPU profile and finite resource budget. Temporal preprocessing is fixed: named float32 `[1,6,64,64]` frame-pair input, RGB, nearest stretch, unit byte scaling, zero bias and `[1,1]` script-position output. Other providers or implicit fallback refuse. Model outputs remain unqualified inferred positions; no object detection, anatomical observation, confidence calibration or physical result follows.

Before launch, the parent reserves an aggregate worker slot/memory and declared snapshot storage. It captures worker, model and runtime from regular descriptors into a private temporary directory and compares exact size/hash to admission. Each file is bounded to 1 GiB and the total to configured snapshot admission. Staging checks cancellation/deadline at file boundaries and before launch; filesystem stall latency is not qualified. The original files are never executed or loaded directly by this path. Snapshot files remain read-only, with executable permission only for the private worker. No credential or project path is supplied.

Finite jobs and persistent workers share the same Linux confinement builder: namespaces, no network, readonly system libraries and admitted files, bounded tmpfs, readonly root/proc/dev mounts, cleared environment, cgroup memory/CPU/process limits and process resource limits. The live role mounts only captured model/runtime files at fixed guest paths. Other platforms refuse explicitly. This refactor does not qualify the sandbox, system-library closure or other operating systems for release.

The worker initializes its model once, emits a checked readiness record, then reads bounded pair headers and exactly 24,576 raw RGB bytes. Each half must match the issued frame's SHA-256 and fixed byte length. Sequence numbers and current frame IDs strictly increase; pair clocks must match the admitted epoch/presentation mapping. `pair_analysis_elapsed_ns` measures pixel preprocessing plus model execution, separately from capture age, native-call telemetry and physical response. Responses echo attempt, full capture identity, profile digest and exact issued pair/byte identities. The parent checks that correspondence before returning a position. Any failed exchange permanently closes the worker; no automatic replay or provider substitution occurs.

The parent accepts only opaque `LiveRgbWork`, borrowed while the capture owner retains it. The caller still owns fresh capture authorization and scheduler completion, including stale/retired-result refusal. The transport has one bounded input channel, one bounded response channel and one exchange at a time. Input copying and header/process-control buffers are additional bounded host memory outside retained pixel admission; guest tensors/model memory are bounded by worker admission. This is not whole-system memory qualification.

An independent watchdog kills the owned cgroup/process tree and reaps the child on cancellation or absolute expiry, including while the owner is idle. Dropping the handle also closes input, kills/reaps the process and joins transport/diagnostic/watchdog threads. Expired workers are not reopened. Reservation and temporary snapshots remain conservatively owned until handle drop. The budget is at most thirty seconds and has no renewal.

The authored acceptance graph produces input-dependent positions for three distinct chronological pairs through the actual ONNX runtime in the same process. Native fixtures also exercise cancellation, expiry while idle before the next API call, byte-identity refusal and unsupported-provider refusal. Raw inputs/results and previous failed verification attempts are retained. A 24,576-value float32 reduction differed from ideal arithmetic by approximately four millionths; the fixture comparison permits `1e-5` absolute error and does not alter outputs or train/tune a model. This numerical wiring check is not a model-quality gate.

Authenticated lease admission/consumption/result checks and failure retirement are integrated above. Required successor work is source acquisition, continuity/renewal rules, measured clocks, actual buffering and device scheduling. GPU fastest-preset six-axis requirements, qualified models/fallback, Handy hardware and full platform/media/human/release gates remain unchanged.
