# Removing retained CUDA evidence

`pulsar live-capture remove-evidence PROJECT CURRENT_REVISION CAPTURE_EPOCH MANIFEST_SHA256 --request-id REMOVAL_REQUEST --confirm-removal` removes one retained capture's original artifact row. Obtain the manifest hash with `live-capture evidence` before requesting removal. The Engine requires current authentication, project Read and ManageGrants permission, and a matching current revision for a new removal request. Removal does not change the motion program or project revision.

The existing bounded original-evidence reader checks the saved admission membership and original artifact correspondence before deletion. A wrong manifest hash refuses removal. The logical deletion and typed receipt are committed in the same transaction as the request journal. Retrying the identical request ID and intent returns the saved receipt after checking current authority; changing the intent with that request ID conflicts. A new request for an absent row returns NotFound.

The receipt identifies the project, capture epoch, manifest and original-byte count. `physical_erasure` is always false. Removing a database row does not securely erase SQLite pages, journals, backups, or earlier exported files. An already admitted download retains its immutable original bytes and memory admission until the existing abandonment, revocation or expiry rules retire it. New downloads and inspection cannot find the removed row.

Verification is recorded under [the removal packet](evidence/roadmap-2026-10-08/live-cuda-evidence-removal/). Scratch-database command tests cover success, receipt replay, conflicting intent and revoked authority; storage tests cover transaction rollback and an admitted original download surviving removal. Native CLI refusal checks deliberately preserve the authored retained capture. The first authorization test incorrectly assumed Grant replaced rather than accumulated scopes; its failure and correction are retained. The initial added handler test also used the wrong nested inspection field and its compile failure is retained.
