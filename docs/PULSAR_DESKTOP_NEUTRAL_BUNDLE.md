# Desktop atomic neutral bundle export

The desktop portable panel offers “Export six-axis bundle” for the current project/revision and “Resume retained six-axis bundle” for an explicit staging path. Both use the existing shared atomic publisher through the owned transfer lane. Export leaves the master unchanged and creates no generation job. The output contains six neutral scripts and hidden recovery metadata; no source media or full project package is included.

Requests capture the project/revision and path by value. Missing context, relative paths and busy states disable submission. Resume takes its project/revision and exact request identities from the retained intent, with current authorization and revision checks in the helper. Local stop cancels the helper control while ownership remains until the worker drains; it does not cancel Engine effects. Progress is indeterminate and returns to idle on completion.

Typed failures retain staging paths and publication outcomes. Unknown publication or unconfirmed durability disables further publication until an operator explicitly records that they inspected and handled the outcome. That local acknowledgement does not resolve Engine unknown outcomes, alter files or create new request identities. NotPublished permits explicit exact-intent resume, though individual exports may already have completed or remain unknown.

Drawn headless button tests cover request capture, invalid/busy inputs and uncertain outcome refusal. A transfer-control test checks cancellation and typed recovery mapping. Initial test compile/lint failures are retained. Exactly three client source paths changed; Engine/Protocol sources remain unchanged and no fresh library suites are claimed for them.
