# Bundled media fixture compatibility

The orientation regression previously tried to encode its source with libx264. The pinned bundled FFmpeg n9.0.2 has no such encoder and refused with exit 8 before the decoder ran. This was a test-construction dependency, not demonstrated faulty rotation decoding. The earlier failure remains in the [CPU admission checkpoint](evidence/roadmap-2026-10-11/cpu-admission/checkpoint.json).

The fixture now generates native MPEG-4, and a separate test retains H.264 decoding coverage using a small first-party authored testsrc2 clip. The [H.264 fixture identity and origin](../crates/pulsar-engine/tests/fixtures/rotation-h264.md) are recorded beside its bytes. The selected tools add a 90-degree display matrix without re-encoding; tests require the exact codec, 96 by 64 packed-source dimensions and actual rotation metadata. Both cases decode plain and rotated sources through the actual worker media adapter and require four frames with identical pixels and source times. Independent checks require times 0, 1/2, 1 and 3/2 seconds, 64 by 64 RGB output and changing frame pixels. No encoder fallback or test skip was added.

This change affects tests and their authored fixture only. Production media handling, authority, resource limits, runtime/model selection and fallback behavior are unchanged. The [checkpoint](evidence/roadmap-2026-10-11/bundled-media-fixtures/checkpoint.json) records source and tool identities, completed bundled/system decoder and library checks, and cleanup. These adapter/process tests do not establish complete Engine import/generation custody, rendered GUI, all-format/media coverage, model quality, offline edition/platform/device or human/release acceptance. No annotation or training was fabricated. Full roadmap PARTIAL; goal active.

Final all-feature Engine checks pass 845 tests (90 ignored) using the pinned bundled FFmpeg, FFprobe and CPU ONNX runtime. The two final rotation cases also pass with system FFmpeg/FFprobe. Strict default/all-feature Clippy, formatting, 402 architecture checks and 36 guards pass. The first extracted-helper lint run failed on five redundant borrows; these were corrected and the final source was rebuilt and rerun. Production application/worker binary hashes remain unchanged from the preceding CPU admission checkpoint. Default bundled Engine passes 831 tests (64 ignored). Owned scratch `/mnt/4tb/tmp/pulsar-bundled-media-fixtures` was removed after all command handles completed and an accessible process scan found no references. The scan discloses permission/race errors. Safe evidence and the authored H.264 fixture remain in the project; borrowed assets are preserved.
