# Official YOLO11 candidate integration probe

The official Ultralytics YOLO11n weights now have an actual CPU export and Pulsar worker probe. This is an unqualified generic COCO80 detector, with no target/view training annotations or useful motion-quality evidence. It is not selected as an edition default and does not close generation model delivery.

The source weights came from the official Hugging Face model repository at revision `8b8ac7d1fae7468f85dbf89670dd66f41f485aab`: 5,613,764 bytes, SHA-256 `0ebbc80d4a7680d14987a577cd21342b65ecfd94632bd9a8da63ae6417644ee1`. An isolated environment used Ultralytics 8.4.175, ONNX 1.20.1 and the existing Torch 2.11.0+cu130 installation. Export ran on CPU with networking disabled, automatic installs disabled, opset 17, static 640 square input, batch one, FP32, no simplification and no embedded NMS. ONNX checker passed; no external tensor initializers were found. The 10,701,972-byte exported model has SHA-256 `36849cda776713a29472569fc5955b6015994f1b2f0063ac53427c9b8340fb74`, FLOAT input `[1,3,640,640]` and output `[1,84,8400]`.

The retained candidate is `/home/brianklam/Projects/Funscripts/assets/pulsar-yolo11-candidate-2026-10-11`. It includes original weights, exported weights, publisher model card, source metadata, exporter/probe scripts, package install logs, actual tensor report and an inert pack with the upstream AGPL license. The pack explicitly declares RGB NCHW stretch preprocessing. This differs from the publisher predictor's usual letterbox preprocessing: matching tensor shapes does not establish numerical or predictive parity.

Using the existing runtime candidate binary and pinned ONNX Runtime 1.27.0, a private Engine imported and selected the pack under explicit unqualified native-execution authority. This affected only disposable probe state. Networking was disabled. The confined worker completed a four-frame authored-media generation job, and project preview returned analysis `available` with zero detections. Standard export correctly refused unresolved missing-detection and missing-motion evidence. No usable script, positive detection quality, target quality or human acceptance is claimed. The initial export refusal and a disk-backed startup timeout are retained alongside the successful private-tmpfs worker probe.
