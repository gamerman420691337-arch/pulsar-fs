# Reference clock declarations

Live-reference training manifests now support schema 2. Every entry must include integer `reference_offset_ms` in the inclusive range -86400000 to 86400000. Script time is source elapsed time plus this offset. A value of 250 means script time 250 ms corresponds to the first decoded source frame. Schema 1 retains its implicit zero offset and rejects the new field; schema-1-only manifest readers refuse schema 2.

This is an explicit declaration, not independently measured alignment. The adapter does not estimate an offset from model output, optimize it against holdout scores or use sterile inputs. Original source PTS and rational timebase are retained. Clip selection subtracts the offset from the chosen script timestamp; training labels add it to exact source elapsed time. Unsupported script times still omit labels rather than extrapolating.

The staged manifest preserves the exact admitted original bytes and hash, including its formatting. Intake entries record the declared offset. Both the holdout driver and production-worker development intake require those offsets to match the bound manifest before creating output. Worker label reconstruction uses the same declaration; complete supplied edges map to source time by subtracting it. Partial boundary edges remain excluded and integer-percent positions retain their travel. This does not change the benchmark matcher or production inference.

The [local evidence](evidence/roadmap-2026-10-01/reference-clock-declarations/validation.json) covers signed-offset admission, tampered/duplicate identities, schema fencing, labels versus complete edge clocks, actual authored FFmpeg staging and byte-exact manifest preservation. The Python suite also performs optimizer/export/ONNX evaluation on authored arrays; the separate JavaScript case exercises the confined worker and unchanged scorer with an authored temporal model. No private training corpus, learned candidate, sterile reference or physical device was used in this increment.

The existing learned candidate remains unqualified. Its consumed development holdout failed to improve constant baselines, and the prior native worker comparison matched zero supplied strokes. No offsets were retroactively assigned to those inputs and no private model was retrained. Independent source-family/alignment and target/projection annotations, useful model quality, Handy evidence and platform/human/release acceptance remain open.
