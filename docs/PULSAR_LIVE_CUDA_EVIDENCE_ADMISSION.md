# Live CUDA final evidence admission

Consuming private CUDA Finish now reserves 512 MiB of cooperative Engine memory before receiving or parsing final evidence. The returned evidence owns that reservation until it is dropped. It occupies no additional worker slot. Child/cgroup, GPU and captured-image custody still retire under the original stream deadline before successful return; retaining evidence does not retain those execution resources.

The sealed evidence object retains canonical manifest and summary bytes alongside the exact original receipt and trace. Readback bounds each blob before parsing (1 MiB manifest, 4 KiB summary, 64 KiB receipt, 8 MiB trace), rejects noncanonical control bytes, and rechecks manifest/summary, SDK device, successful-run count, guest output path and original trace correspondence. Native receipt and trace JSON are never normalized. The reader uses a local strict SDK observation schema rather than importing native worker code; default-feature tests require no CUDA runtime. This is not cross-platform runtime qualification or a hard OS memory limit.

Three deterministic tests read the preceding retained native packet, preserve original bytes through canonical readback, retain/release the memory claim, refuse insufficient capacity, and reject ten malformed, changed, oversized or noncanonical inputs without leaking admission. Existing private native fixtures now keep the evidence claim through inspection/output and verify full capacity returns only after dropping evidence.

Verification results and source/input identities are retained in [the evidence packet](evidence/roadmap-2026-10-07/live-cuda-evidence-admission/). Final serial gates pass 1,011 workspace tests (54 ignored), 535 CUDA Engine tests (53 ignored), the explicit native Engine case and all eight private stream cases, nine CPU application cases without skips, the default build and 261 structural checks. Native readback retains three runs/nine CUDA computation events in each successful Engine/stream case. Six scoped source records match; comparison with the preceding checkpoint finds 346 unchanged records and only five intended existing-source changes. Eighty native/model supplier records also match. No parallel-failure closure or qualification is implied.

Previously retained parallel-test failures remain unresolved; these serial gates do not close them. Database publication, schema-21 reader barriers, Engine finalization authority checks, public GPU startup/scheduling, continuation and exhaustive recovery remain unfinished. The readback object proves consistency, not the origin or authorization of caller-supplied bytes. Only an Engine finalizer consuming its actually owned worker may authorize publication. Model/media, fastest-preset six-axis, Handy, platform, human and release gates remain open. See [ADR B3-061](../research/phase-b/ADR-B3-061-live-cuda-evidence-admission.md).
