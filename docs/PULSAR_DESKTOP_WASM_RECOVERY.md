# Desktop WASM invocation recovery

Status: software/controller increment verified; roadmap PARTIAL. Saved recovery facts are not execution approval or a standing grant.

Before sending an identified WASM start, the desktop publishes a private, bounded journal record with the original request ID, project/revision, module manifest and worker identity, guest-memory declaration and label. The journal is bound to the authenticated session, a credential digest and the endpoint digest. It contains no bearer credential, owner proof, executable/module/input/output bytes, file paths or approval flag. Publication failure prevents dispatch. A successful checked response records the original attempt ID; a failed acknowledgement publication leaves the unknown original request retained.

A fresh controller loads these facts without restoring a draft, pending execution, selection or approval. The recovery view can inspect acknowledged attempts and explicitly dismiss acknowledged local records. Dismissal changes no engine operation or candidate. Unknown records cannot be dismissed. An authenticated project catalog reconciles matching original request/revision and any completed module/worker receipts; an empty catalog is not proof of nonexecution. Explicit retry requires freshly loaded bytes and approval, exact metadata equality, and the original request ID. Changed declarations, worker or project/revision refuse. No automatic retry or commit occurs.

Storage reuses the private recovery layer: owner-only directories, single-link 0600 regular files, nonblocking locks, inode checks, no-follow handle opening, atomic publication with file/directory syncing, a 1 MiB document limit and at most 64 records. Changed namespace/credential/endpoint, malformed/oversized data, symlink/nonregular storage and exhausted capacity fail while preserving the existing journal. Other platforms explicitly refuse because private recovery storage is currently Unix-only. These checks do not prove preemption of arbitrary filesystem calls or a product deadline.

The client library passes 161 tests with four default-ignored qualifications, including five journal cases and seven panel cases. The explicit native fixture uses actual authenticated control/bulk IPC and a real authored WASM worker: it persists before dispatch, deliberately skips local acknowledgement publication, constructs a fresh session/controller, discovers the original attempt, retries the identified request without creating another invocation, hydrates a candidate while master stays unchanged, and exercises terminal cancellation. It also makes the journal unsafe and verifies a fresh start is refused before dispatch, preserves journal bytes and leaves exactly the original engine operation. The gap is authored acknowledgement-loss testing, not an OS process-death campaign or rendered window test.
