# Portable accepted CUDA evidence

Status: integrated; main Rust/native/feature/build gates pass. Application qualification is PARTIAL after two 99-pass/five-failure campaigns. Production GPU admission remains disabled.

Format 10 carries explicit accepted candidate, original canonical request digest and original CUDA receipt/trace identities. Capture preserves the general worker receipt and dependency lineage separately. Imported evidence is inert: it creates neither active attempts nor device grants. Clone, restart, re-export and second clone retain the original namespace facts and format requirement.

Conditional schema 18 preserves the required active worker-fence/intent/evidence table set through an exact marker. Archival-only import needs no active CUDA table. Genuine later activation updates the requirements in the same transaction; deletion of a required table refuses. Startup validates retained original request and CUDA anchors from owned evidence namespaces before writable database initialization. Package-provided original filesystem paths are never used as destination resolvers.

The first workspace run exposed a stale client probe that expected format 10 to be unsupported. The corrected test admits format 10 and rejects format 11; its initial failure and preceding source subject are retained.
