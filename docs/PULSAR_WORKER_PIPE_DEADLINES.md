# Worker pipe deadlines

The ordinary Linux worker launch now uses nonblocking stdin, stdout and stderr. One parent monotonic deadline begins before spawn and request delivery. Reads of the response header, artifact chunks and final EOF, request writes and process-exit polling check the same cancellation token and deadline. Response processing has no reader/diagnostic threads to join. Diagnostics retain at most 16 KiB while continuing to drain excess bytes; each tick reads at most 8 KiB so a diagnostic flood cannot starve deadline checks. Cancellation returns a non-retryable IO error because Rust's `read_exact` retries `Interrupted`.

The parent checks cancellation and expiry again after its output accounting and directory synchronization, before returning successful launch evidence. Existing fixed artifact sequence, bounds, independent hashes and CUDA evidence verification remain in effect. Errors signal the owned worker cgroup and child, then enter [retirement custody](PULSAR_WORKER_RETIREMENT.md).

This is pipe supervision, not a hard end-to-end return deadline. Command preparation, spawn, artifact storage, hashing, synchronization, cgroup filesystem operations can still block. Ordinary job reservations now remain held until direct-child exit and an empty cgroup are confirmed; unconfirmed retirement transfers to a reaper. Restart custody and production engine GPU launch remain unfinished. The private CUDA bootstrap uses its separate research launch helper; these ordinary-launch changes do not enable GPU scheduling or qualify that helper's parent IO.

The [source-bound packet](evidence/roadmap-2026-10-01/worker-pipe-deadline/validation.json) records the final gates. Five owned-pipe tests exercise held-open output, blocked request delivery, cancellation through `read_exact`, a 1 MiB diagnostic flood and draining after diagnostic retention fills. Configured application cases exercise rebuilt ordinary confined generation and preview. These are authored/local cases, not model, real-media, hardware or release qualification.
