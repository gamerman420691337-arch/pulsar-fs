# Desktop bundled model preparation

The Generator's model controls now include a bundled-model panel. After a native window is created, the trusted executable supplies a read-only discovery callback. Complete cache verification runs on a background thread and returns through a one-result bounded channel. The client validates the bounded report, identities, pack declarations, namespace paths and absence of execution/rights/qualification authority. Loading, bounded errors and retry remain local presentation state. A launcher without this callback reports that discovery is unavailable.

Each discovered pack displays its declared identity, source description and label count. “Prepare pack import” fills the existing offline-pack directory and manifest fields. It clears draft execution approval and prior integrity/catalog association, preserves the current recorded selection, and refuses changes during a pending/recoverable operation. It sends no RPC and imports nothing. The existing “Import inert pack”, current-owner refresh and explicit selection controls remain separate actions with their existing Engine checks. A late discovery report cannot grant execution approval.
