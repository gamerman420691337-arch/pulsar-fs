# Issued-work binding for private live CUDA

The private CUDA parent now takes opaque RGB work issued by its bound runtime. A process-local owner scope rejects work from another runtime even when its serialized identity and clock match. The parent builds input declarations from actual work and sends its borrowed pixel slices. Both parent and worker reject discontinuous reuse of previous-frame pixels or source clocks before native execution.

Eight authored native cases passed against a newly rebuilt, frozen CUDA worker and the actual 75-library capture. They cover successful Finish, parent replay, cancellation, original-deadline idle expiry, foreign runtime work, worker-side replay, mismatched pixels and mismatched Finish. The idle cases independently observe watchdog exit without pipe monitoring, then verify custody is still retained before cleanup. Every case checks complete GPU/RAM/slot, captured-image storage, staged snapshots and worker-fence retirement.

The successful stream uses runtime-issued constant RGB frames with values 0, 64, 128 and 192. Its three exchanges produce three model runs and nine CUDA computation events through one loaded authored temporal model. Independent readback reconstructs the manifest and transcript, verifies the original trace and the formula `0.25 + 0.5 * mean(two normalized RGB frames)`, and checks overlapping pixel/clock identities. Runtime completion accepts two results and rejects one as stale; all three successful native runs remain in the final transcript. Capture and completion ticks are authored inputs, so this is not measured capture latency or learned-model quality evidence.

The [evidence packet](evidence/roadmap-2026-10-07/live-cuda-issued-work/) retains the exact 346-path source subject, worker identity, declared native/model inputs, original exchanges/receipt/trace, focused checks, native-case readback and regression logs. The native test passes all eight cases in 141.17 seconds. Nine protocol checks and 33 focused engine live checks pass. Broad regression results are recorded in the packet's gate ledger.

Final serial gates pass 995 workspace tests (53 ignored) and 524 CUDA engine tests (51 ignored). The default build, four CPU live cases, five shipped CPU regressions, one ordinary-reader compatibility case and 259 architecture checks pass; the application/reader cases have no skips. All 346 archived/current source records and 80 declared native/model inputs match after execution.

Scope validation does not establish current authority, runtime activity or freshness.
